# JeoParty 🎮

**JeoParty** is a full-stack Jeopardy-style trivia web application currently being developed using modern web technologies including React, ASP.NET Core Web API, SQLite, and Tailwind CSS.

> ⚠️ This project is currently **in progress** and actively being expanded with new gameplay features, UI improvements, and backend functionality.

---

# Project Overview

JeoParty is designed to recreate the experience of an interactive trivia game inspired by Jeopardy while also serving as a portfolio project to strengthen my full-stack development skills.

The application allows users to:

* View categorized trivia questions
* Select question values from a game board
* Reveal questions and answers
* Track scores in real time
* Interact with a responsive game interface

This project focuses heavily on learning backend architecture, API development, database integration, and object-oriented programming concepts using C# and ASP.NET Core.
